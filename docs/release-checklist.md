# Clipeshare リリース前チェックリスト

最終更新: 2026-07-05

このチェックリストは、本番公開前または大きな機能追加後に実機で確認する項目です。
コマンド確認だけでなく、PC/スマホのブラウザ操作を含めて確認します。

## 0. 前提

- 対象URL: `https://clipshare.link`
- 確認ブラウザ:
  - PC Chrome
  - スマホ Chrome または Safari
- 確認アカウント:
  - 一般ユーザー
  - 管理者
  - 未ログイン

## 1. サーバー/デプロイ

- [ ] GitHub Actionsの最新Deployが成功している
- [ ] `https://clipshare.link` が表示できる
- [ ] SSL証明書エラーがない
- [ ] CSSが適用されている
- [ ] `/api/health` が成功する
- [ ] Next.js app serviceが起動している
- [ ] video worker serviceが起動している
- [ ] Nginxが `_next/static` と `/media` を正しく返す
- [ ] サーバー容量に十分な空きがある

## 2. 認証

- [ ] 未ログインでトップページを閲覧できる
- [ ] Discordログインできる
- [ ] メールリンクログインのメールが届く
- [ ] メールリンクからログインできる
- [ ] ログアウトできる
- [ ] BAN済みユーザーが投稿できない

- [ ] 投稿数が表示される

- [ ] よく投稿するゲームが表示される
- [ ] 投稿一覧が表示される

## 4. スクリーンショット投稿

```bash
node scripts/check-share-metadata.mjs https://clipshare.link/c/{ID}
```

```text
https://clipshare.link/c/{ID}?v=1
```
