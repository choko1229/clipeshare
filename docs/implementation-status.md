# Clipeshare 実装状況

最終更新: 2026-07-05

この文書は `docs/overall-design.md` のMVP要件と現在の実装を比較したものです。
状態は以下で分類します。

- 完了: コード上で主要機能が実装済み
- 一部完了: 基本実装はあるが、仕様の一部が不足
- 要実機確認: コード上は実装済みだが、本番環境や外部サービスでの確認が必要
- 未実装: 仕様に対して未着手または実装が見当たらない
- 保留: ユーザー判断または外部サービス準備が必要

## 優先して残っている作業

1. 本番実機チェック
   - ログイン、投稿、動画変換、共有、管理画面を実際に通す。

2. NSFW自己申告フローの確認/補強
   - 年齢確認済みユーザーだけ表示できる流れを画面上で明確にする。

3. 削除済み/元動画保持期間の自動処理

4. 禁止コンテンツ/モデレーション運用文書
   - 犯罪系禁止、NSFWでも不可の内容、対応基準を管理者向けに固定する。

5. 共有の外部サービス実機確認
   - Discord / X は外部キャッシュや仕様に左右されるため、本番URLで確認する。

6. ゲーム情報の追加同期方針
   - IGDB以外にSteam/RAWGを使うか、手動管理中心にするか決める。
